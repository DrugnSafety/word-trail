
파일 이름은 `번호_영상제목.확장자`이고, 번호는 플레이리스트 순서예요.

## 4. 파일 형식

### (1) 쉐도잉 정리본: `*.md`, `txt_1_shadowing/*.txt`

- 문장부호와 대소문자, 등장인물 이름(Bluey, Bingo, Bandit, Chilli, Muffin, Socks 등)을 복원함
- 자동 자막이 잘못 알아들은 부분은 확실한 경우에만 고침 (예: "dries without petals" → "drives without petrol")
- 화자가 바뀌면 줄을 나눔
- 한 줄은 따라 읽기 쉬운 3~10단어 단위
- [Music], [Applause], "foreign" 같은 소음 표시는 지움

```
[00:30 - 00:35] Ring, ring, ring, ring. Hello, pizza shop!
[00:35 - 00:37] Would you like to order a pizza?
[00:37 - 00:37] Yes, please.
[00:37 - 00:42] I want one supreme with no mushrooms.
```

### (2) 유튜브 원본: `txt_2_youtube_original/*.txt`

- 유튜브 자막을 시간대별로 잘린 그대로 담음 (텍스트는 수정하지 않음)
- 소음 표시([Music] 등)만 지우고, 끝 시간은 다음 줄의 시작 시간에 맞춤

```
[00:30 - 00:35] ring ring ring ring hello pizza shop
[00:35 - 00:37] would you like to order a pizza yes
[00:37 - 00:39] please I want one supreme with no
[00:39 - 00:42] mushrooms
```

## 5. 참고 사항

- **정리본의 정확도**
  - 짧은 클립은 대부분 공개된 에피소드 대본과 대조해서 고침
  - 긴 모음집(#02, #04, #07, #10)과 일부 에피소드(#06, #20, #22)는 자동 자막만 보고 다듬어서 틀린 단어가 조금 남아 있을 수 있음
  - #07 중간(약 1:05:00 ~ 1:30:00, Bingo / Asparagus / The Sleepover)은 원래 자동 자막이 특히 부정확해서 정리본도 어색한 부분이 있을 수 있음
- **시간 정확도**
  - 자동 자막은 문장 중간에서 끊기기 때문에, 한 구간을 여러 줄로 나눈 경우 시간은 단어 수 비율로 추정함 (1~2초 정도 오차 가능)
- **줄 길이**
  - 정리본은 짧게 끊은 편이고, 일부 줄은 14단어가 넘음 (#10에 많음)
- **특이한 영상**
  - #11 (Rain 클립): 대사가 거의 없어서 한 줄뿐임
  - #63, #76, #77: 아주 짧은 클립이라 4~6줄

## 8. 접근 방식과 처리 과정

### 전체 흐름

```
플레이리스트 목록 추출 → 자막 수집 → 원본 자막 정리 → 문장 복원과 쉐도잉 단위 분할 (병렬)
→ 긴 영상 보완 → 검수 → txt 두 가지 버전으로 변환
```

### 단계별 처리

1. **플레이리스트 목록 추출**
   - 브라우저에서 하나씩 누르지 않고, 플레이리스트 페이지에 들어 있는 데이터에서 영상 ID와 제목을 한 번에 뽑음
   - 같은 영상이 두 번 들어 있는 경우(#23 Cubby)는 하나로 합쳐서 85개로 정리

2. **자막 수집**
   - 영상마다 유튜브 영어 자막을 시간 정보와 함께 가져옴 (6개씩 동시에 요청)
   - 영상별로 어떤 자막이 있는지 확인해서, 사람이 만든 자막이 있으면 그걸 우선 사용
   - 확인해 보니 82개가 자동 생성 자막뿐이었음. 그래서 "그대로 저장"만으로는 쉐도잉에 쓰기 어렵다고 판단하고 문장 복원 단계를 추가함

3. **원본 자막 정리** (→ `txt_2_youtube_original`)
   - [Music], [Applause], "foreign" 같은 소음 표시 제거
   - 자동 자막은 줄끼리 시간이 겹쳐서(예: `[00:33 - 13:53]`처럼 끝 시간이 비정상적으로 긴 경우) 끝 시간을 다음 줄의 시작 시간으로 맞춤
   - 이 파일을 다음 단계의 입력 자료로도 사용

4. **문장 복원과 쉐도잉 단위 분할** (→ `*.md`)
   - 공통 작업 지침을 파일 하나로 만들어 두고, 84개 영상을 분량이 비슷하게 8개 묶음으로 나눠서 AI 작업자 8개가 동시에 처리
   - 지침의 핵심 규칙
     - 말한 단어는 그대로 두고 문장부호, 대소문자, 이름만 복원
     - 잘못 알아들은 단어는 확실할 때만 고침. 요약이나 바꿔 말하기는 하지 않음
     - 화자가 바뀌면 줄을 나누고, 한 줄은 3~10단어
     - 시간은 원래 자막 구간을 따르고, 한 구간을 여러 줄로 나누면 단어 수 비율로 나눔
     - 모음집은 "This episode of Bluey is called ..."가 나오는 곳에 에피소드 제목을 넣음
   - 짧은 클립은 작업자가 공개된 에피소드 대본과 대조해서 고친 경우가 많음. 긴 영상은 자막만 보고 다듬음

5. **긴 영상 보완**
   - 2시간짜리 #07은 작업 시간 제한에 걸려서 10분 정도에서 멈춤
   - 남은 부분을 5개 구간으로 나눠서 다시 동시에 처리한 뒤 이어 붙임
   - 합치는 과정에서 빠진 에피소드 제목 4개(Pizza Girls, Faceytalk, Baby Race, Movies)를 채우고, 섞여 들어간 불필요한 태그를 지움. 최종적으로 에피소드 18개 확인

6. **검수**
   - 파일마다 줄 수를 세고, 5줄 미만인 파일은 원본 자막과 비교 (#11 Rain은 실제로 대사가 거의 없음을 확인)
   - 14단어가 넘는 긴 줄이 있는 파일 확인 (#10에 36줄, 나머지는 몇 줄 수준)
   - 파일 앞부분을 직접 열어서 형식과 문장 품질 확인

7. **txt 두 가지 버전으로 변환**
   - `txt_1_shadowing`: md 정리본에서 Markdown 기호만 빼고 그대로 옮김
   - `txt_2_youtube_original`: 3단계에서 정리한 원본 자막에 제목, 링크, 길이 정보를 붙여서 저장

### 판단한 부분

- **동영상 다운로드**: 공식 채널의 저작권 영상이라 외부 다운로드 사이트는 쓰지 않고, 정식 오프라인 시청 방법을 안내함
- **자막 품질 문제**: 자동 자막을 그대로 쓰면 문장이 중간에서 끊겨 따라 읽기 어려워서, 요청하신 "쉐도잉하기 좋게"에 맞춰 문장을 복원함. 대신 원본도 따로 남겨서 비교할 수 있게 함
- **대량 처리**: 전체 약 8만 5천 단어 분량이라 한 번에 처리하지 않고, 같은 지침으로 나눠서 동시에 처리해 결과 형식을 맞춤
