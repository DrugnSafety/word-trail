# 단어 연습 고도화

2026-09-28 · 기존 콘텐츠 버전과 저장 형식을 유지한 기능 개정

이 문서는 9월 28일 구현 기록이다. 9월 29일 개정에서 수동 표현 묶기 UI를 삭제하고 알파벳 이름 음성·대화 구간·완료 목록을 변경했다. 현재 동작은 [LEARNING_REVISION.md](LEARNING_REVISION.md)를 참고한다.

## 학습 순서와 조작

듣기 → 받아쓰기·단어 선택 → 단어 연습의 큰 흐름을 유지한다. 단어 연습은 다음 순서로 진행한다.

1. 뜻·표현: 뜻과 일상 대화, 관련 단어 묶음을 살펴본다.
2. 짚어 읽기: 원문에서 선택 단어/표현의 위치를 확인하고 소리와 글자를 연결한다.
3. 철자 쓰기: 보이는 단어를 쓰며 입력한 글자 이름을 듣는다. 글자와 입력 중인 단어가 확대되는 짧은 효과를 제공한다.
4. 빈칸: 원문 맥락에서 단어/표현을 쓰고 해당 항목의 기기 음성을 반복해서 듣는다.
5. 소리 퀴즈: 철자를 가린 상태에서 반복 음성을 듣고 쓴다.
6. 뜻 퀴즈: 한국어 뜻으로 영어를 떠올린다. 한국어 뜻이 없거나 뜻에 답이 그대로 포함되어 있으면 이 단계만 건너뛴다.
7. 혼자 읽기: IPA와 강세 기호를 참고해 읽고 부모가 확인한다. ‘혼자 읽었어요’만 성공으로 기록하며 기존 1·3·7·14일 복습 규칙을 적용한다.

뜻·표현/짚기에는 정답 판정이 없으므로 ‘뜻을 살펴봤어요’, ‘짚어 읽었어요’로 진행한다. 채점 단계는 확인/Enter로 제출하고 **저장 성공 후 1.1초 동안 피드백을 표시한 뒤 자동 진행**한다. 오답·저장 실패·도움이 필요한 읽기는 자동으로 넘기지 않는다. 자동 진행을 끄거나 원하는 단계/단어로 이동할 수 있다. 마지막 단계가 끝나면 다음 선택 단어로, 마지막 단어에서는 요약 화면으로 이동한다. 다음 영상을 자동 재생하지 않는다.

왼쪽 공간은 영상 대신 선택 항목 목록과 진행 안내에 사용한다. ‘영상으로 돌아가기’로 듣기 단계에 복귀한다. 받아쓰기 답과 확정한 선택 항목은 유지된다. 퀴즈 중에는 목록/제목 등 답이 드러나는 영역의 텍스트도 가린다.

## 음성과 접근성

- 단어 연습에 들어갈 때 YouTube 반복 재생을 일시정지한다.
- 철자 음성은 `A`, `B`처럼 글자 이름만 전달한다. `letter`를 덧붙이지 않는다.
- 빈칸/소리 퀴즈는 선택한 항목의 **기기 TTS**를 처음 한 번 재생하고, 발화 종료 후 1.6초 간격으로 반복한다. 영상에서 해당 단어의 오디오만 추출한 기능은 아니다.
- 반복 시작/멈춤 버튼 제공. 단계·단어·영상·계정 변경, 화면 이탈, 숨김 탭, 대화상자 열기에서 반복/철자 음성과 지연 이동을 취소한다. 숨김 탭에서 돌아와도 반복을 자동 재시작하지 않는다.
- OS의 모션 줄이기 설정에서는 입력 확대 애니메이션을 실행하지 않는다.
- IPA의 `ˈ`/`ˌ`를 강조하고 주강세/부강세를 설명한다. 미수록 발음기호나 강세를 추측해 생성하지 않는다. 기존 학습용 IPA는 영상의 호주 영어 발음과 다를 수 있다.

## 표현 묶기와 관련어

표현은행에서 원문에 연속해서 나타나는 다단어 표현을 후보로 제시한다. 직접 묶기에서는 시작 단어와 끝 단어를 고르며 문장 부호를 넘는 묶음은 막는다. 직접 만든 묶음을 모두 숙어라고 표시하지 않는다. 묶음도 하나의 선택 항목으로 철자·빈칸·소리·뜻·읽기 연습에 사용한다.

기존 `word:<term>` 기록과 원문 인덱스를 재사용한다. 표현의 모든 단어를 하나의 빈칸으로 가리고, 반복 출현은 겹치지 않는 각 묶음으로 처리한다. HTML 교재는 첫 출현 전체를 빈칸으로 내보낸다. 표현 후보의 화면 전용 메타데이터는 저장하지 않으므로 DB 마이그레이션이 필요하지 않다. 새로고침·정답 재제출 뒤에도 등록 이력을 보존한다.

관련어는 `content/word-families.json`의 **39개 묶음, 131개 예시 항목, 208개 검색 형태**를 사용한다. 현재 Faceytalk 내장 어휘 271개 중 48개 형태에 연결된다. 예: help → help(동사/명사), is helping(진행형 구문), helpful(형용사), helpfully(부사). 단순 어형 변화와 의미상 관련어를 구분하며, 모든 단어에 존재하지 않는 품사를 억지로 만들지 않는다. 미수록 항목은 준비 중으로 안내하고 원문/철자 연습은 계속 제공한다. 외부 유료 생성 API는 사용하지 않는다.

## 학습 근거

- [IES: Foundational Skills to Support Reading for Understanding in Kindergarten Through 3rd Grade](https://ies.ed.gov/ncee/wwc/Docs/PracticeGuide/wwc_foundationalreading_040717.pdf): 말소리와 글자의 연결, 단어 해독·쓰기, 연결된 문장 읽기를 지지하는 지침이다.
- [IES: Teaching Academic Content and Literacy to English Learners](https://ies.ed.gov/ncee/WWC/PracticeGuide/19/Published): 어휘를 여러 날에 걸쳐 다양한 말하기·읽기·쓰기 활동으로 연습하도록 권한다.
- [British Council: Lexical approach](https://www.teachingenglish.org.uk/professional-development/teachers/knowing-subject/lexical-approach-1-what-does-lexical-approach): 함께 쓰이는 다단어 덩어리를 학습 단위로 다루는 관점을 설명한다.

이 앱의 정확한 7단계 순서는 위 원칙을 참고해 **도움을 받는 연습에서 회상으로 이동하도록 정한 설계 판단**이다. 이 순서 자체나 자동 전환 시간이 학습 효과를 입증한 실험 결과라는 뜻은 아니다. IPA는 보조 수단이며 부모와 실제 소리를 듣고 읽는 과정을 대체하지 않는다.

## 검증 실행

`npm run build`, `npm test`, `npm run check`로 자료 생성·회귀 테스트·구문을 확인한다. 별도 브라우저 검증은 `scripts/qa-practice.mjs`에 있다. 이미 설치된 Playwright를 사용하며 앱 의존성에는 추가하지 않았다.

```sh
PORT=4174 npm start
# 다른 터미널: 기존 Playwright 모듈 경로와 Chrome 실행 파일 경로를 환경에 지정
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs QA_CHROME=/absolute/path/to/chrome node scripts/qa-practice.mjs
```

브라우저 테스트는 새 격리 컨텍스트에서 실행하며 사용자의 localhost:4173 진도를 건드리지 않는다. `tmp/qa-practice/`에 결과 JSON, 화면 캡처와 다운로드한 교재를 남긴다. 흐름 검증의 YouTube·TTS는 제어 가능한 대역을 사용하므로 실제 음량/발음 품질을 확인했다는 의미가 아니다. 별도 실제 Chrome 확인에서는 YouTube iframe 준비와 OS 영어 음성 목록을 확인했으나, 영상 시간 진행은 확인하지 못했다(`paused=true`, `readyState=0`). 실제 iPad Safari·가상 키보드·스피커 출력, Supabase 운영 검증·공개 배포는 별도 조건이다.
