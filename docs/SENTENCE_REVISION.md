# 문장 받아쓰기·오답 단어 학습 변경

> 이전 개정의 기록입니다. 현재 학습 단위와 단어 선택 흐름은 [학습실 개편](WORKSPACE_REDESIGN.md) 및 [PRD 1.2](PRD.md)를 따릅니다. 아래의 이전 구간 구성·별도 오답 단계는 대체되었습니다.


사용자 확인 후 요청한 세 가지 수정에 대한 구현 계약이다.

## 결과와 범위

1. 20초 이상으로 여러 cue를 모으던 학습 구간을 **대본의 cue 하나**로 변경한다. 대부분 한 문장 또는 짧은 두 문장이다. 입력 대본이 더 길게 끊긴 경우 임의로 오디오 시각을 추정하지 않고 원래 범위를 사용한다.
2. 무자막 듣기 다음에 **문장 전체 받아쓰기**를 둔다. 제출 전에는 답안 단계·교재·카드를 잠그고, 제출 후 단어 순서를 비교해 다른 철자·누락·추가를 문자와 색으로 구분한다. 대소문자·일반 구두점·공백 차이는 무시하며 축약형의 apostrophe는 유지한다.
3. 오답을 **단어 공부 목록**에 모아 각 항목을 선택하면 바로 해당 단어 연습으로 이동한다. 처음 맞힌 단어는 오답 목록에 넣지 않는다. 재제출로 문장을 맞혀도 이전 오답 학습 기록은 유지한다.

자료가 있는 단어는 기존 한국어 뜻·IPA·두 대화를 사용한다. 없는 단어는 원문·기기 소리·철자 입력을 제공하며 뜻이나 IPA를 추측해 만들지 않는다. 원문에 없는 추가 단어는 그 사실을 표시하고 해당 단어를 뺀 문장으로 연습한다. 단어 입력 정답을 부모가 확인한 읽기 성공으로 처리하지 않는다.

## 데이터와 기존 기록

- 새 구간 ID는 `c0001`처럼 원본 정리 cue ID를 사용한다. 이전의 `s001`과 겹치지 않는다. 콘텐츠 버전은 `2026.09.25-2`이다.
- 이전 진도를 삭제하지 않고 보존하되, 이전 구간 위치를 새 문장 위치로 해석하지 않는다. 이어서 학습은 콘텐츠 버전을 확인한다.
- 문장별 받아쓰기 기록은 기존 표현 진도와 별도로 저장한다. 계정/게스트 격리, 낙관적 저장 충돌 검사, 초기화/내보내기/계정 삭제 범위를 유지한다.
- 문장별 기록은 마지막 답안, 시도 횟수, 누적 오답 단어와 각 단어의 연습 상태를 보관한다. 동일 문장 저장은 직렬화하며 서버 실패를 성공으로 표시하지 않는다. 쓰기 직전에 예상 계정 scope를 검증해 인증 전환 중 다른 계정으로 저장하지 않는다.
- 일일 신규 구간 한도는 기존 기본값 10을 유지한다. 이미 시작한 문장과 단어 공부 재개는 다시 차감하지 않는다.

## 검증 기준

| 항목 | 확인 |
|---|---|
| 짧은 반복 | Faceytalk 첫 구간 26–29초, 모든 새 구간 cue 1개, 출처 범위 일치 |
| 비교 정확성 | 일치, 철자 오류, 누락, 추가, 반복 단어, 축약형, 공백/구두점, 긴 입력 제한 |
| 학습 연결 | 오류 단어 선택 → 그 단어 표시 → 연습 → 결과 기록; 설명은행에 없는 단어도 가능 |
| 기록 | 정답 재제출 후 과거 오답 유지, 새로고침 유지, 계정 전환 격리, 충돌/실패 표시 |
| 회귀 | 기존 빈칸/설명/읽기/교재 기능, 84개 자료 생성, 기존 진도 오연결 방지 |
| 실제 화면 | 데스크톱·태블릿 크기에서 듣기 → 받아쓰기 → 비교 → 단어 선택·연습 |

순서는 비교/분할/저장 테스트와 구현 → 화면 통합 → 독립 리뷰 → 전체 테스트·실제 브라우저 확인이다. 추가 패키지나 유료 서비스는 사용하지 않는다. 실제 Supabase 프로젝트·메일·iPad Safari는 기존과 같이 미검증 외부 조건이다.
