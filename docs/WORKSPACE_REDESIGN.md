# 학습실 개편: 검토와 결정

## 기존 페이지에서 발견한 문제

| 문제 | 원인 | 개편 결정 |
|---|---|---|
| 대사가 1초씩 잘림 | 읽기용으로 다듬은 cue 하나를 학습 단위로 사용 | 원본 캡처 cue 기준, 부모가 제시한 묶음은 별도 manifest |
| 정답을 썼는데도 모두 오답처럼 보임 | 이전 오답의 누적 목록을 현재 결과 화면에 사용 | 이번 답안의 비교 결과와 등록한 단어 이력을 분리 |
| 단어 선택 후 다른 학습으로 연결되지 않음 | 오답 목록과 표현은행 타깃이 별도 체계 | 확인한 선택 목록을 모든 연습의 공통 입력으로 사용 |
| 다음 단계가 불분명 | 일곱 단계와 별도 단어 공부 페이지가 섞임 | 듣기 → 받아쓰기·선택 → 선택 단어 학습의 세 단계 |
| 단어마다 화면 이동이 큼 | 페이지 전환과 내용 길이에 따라 전체 화면 이동 | 동일 학습 공간의 이전/다음 단어, 선택 가능한 연습 종류 |
| 퀴즈가 정답을 노출할 가능성 | 단어 제목·원문·발음기호와 문제를 동시에 표시 | 뜻/소리 퀴즈 중 답안 관련 영역을 숨김 |
| 단어의 학습 맥락이 없음 | 오답 여부와 단일 완료 상태 중심 | 등록일·영상·연습 횟수·종류별 결과 기록 |

독립 critic은 최초 안에 수정을 요청했다. 원문 시간의 겹침, 반복 단어의 식별, 접근성 트리까지 포함한 정답 가리기, 긴 설명에서도 고정된 조작 위치, 모든 연습을 강제하지 않는 흐름을 명시한 뒤 승인했다. 계획과 검토 반영 사항은 [구현 계획](../.omx/plans/learning-workspace-redesign.md)에 있다.

## 학습 문장과 원본의 관계

저장된 `txt_2_youtube_original` 파일도 화면에서 본 YouTube 대본 묶음을 전부 보존한 자료는 아니다. 기본적으로 그 파일의 cue를 따라가되, 사용자가 직접 제시한 Faceytalk 첫 세 묶음은 명시적으로 반영한다. 자동으로 추측한 묶음을 원본의 문장 구분이라고 부르지 않는다.

| 학습 묶음 | 재생 시간 | 근거 |
|---|---|---|
| Mum… / Er… / Please! / Yeah… / Uss! | 26–34초 | 부모가 제시한 첫 묶음; 원본 `Uss!`의 종료 시각까지 포함 |
| But no hogging… | 33–37초 | 부모가 제시한 두 번째 묶음 |
| Bluey, I'm talking… / Yes, Mum. No hogging. | 37–41초 | 부모가 제시한 세 번째 묶음 |

첫 두 묶음은 캡처 시각상 1초 겹친다. 원문을 누락시키지 않으면서 영상 음성과의 정밀 대조가 아직 필요함을 표시한다. 콘텐츠 버전을 변경하므로 기존 구간 기록을 새로운 구간에 위치만으로 옮기지 않는다.

## 선택과 기록의 의미

- **이번 선택:** 현재 받아쓰기에서 빠뜨리거나 다르게 쓴 원문 단어를 자동 선택한다. 추가한 불필요한 단어는 비교 설명에만 나온다. 원문 단어를 눌러 선택하거나 해제할 수 있다.
- **단어장:** 선택을 확인하고 학습을 시작한 단어의 이력이다. 정답으로 다시 받아썼다고 이력이 삭제되지는 않지만, 이전 오답을 이번 선택으로 자동 복원하지도 않는다.
- **등록일:** 처음 학습 목록에 확정한 시각. 과거 자료에 등록일이 없으면 정확한 날짜를 지어내지 않는다.
- **연습 횟수:** 실제 제출·읽기 확인 횟수. 화면을 열거나 단어를 이동한 횟수는 포함하지 않는다.
- **읽기 복습:** 독립 읽기를 부모가 확인한 결과에 따라 1·3·7·14일 복습을 잡는다. 철자 퀴즈 정답은 독립 읽기 성공과 별개다.

## 학습 공간

단어 철자 쓰기, 짚기, 빈칸, 뜻·표현, 뜻 퀴즈, 소리 퀴즈, 읽기 확인은 골라서 사용하는 연습이다. 모든 종류를 순서대로 완료할 필요가 없다. 선택한 단어 안에서 이전/다음으로 이동하고, 언제든 다음 문장으로 넘어갈 수 있다.

철자 입력에서는 새로 입력한 영문자를 크게 표시하고 기기의 영어 음성으로 차례로 읽는다. 음성 볼륨은 브라우저 API 최대값을 사용하지만 기기 음량 자체는 사용자가 조절한다. 붙여넣기·삭제·한글 조합 입력은 글자마다 읽지 않는다.

한국어 뜻과 발음기호는 무료 내장 학습 자료를 먼저 사용한다. 준비되지 않은 단어는 부모가 뜻을 적어 저장하면 뜻 퀴즈를 사용할 수 있다. 기존 표현은행의 새 대화 두 세트는 일치하는 표현에 연결하고, 없는 대화를 생성한 것처럼 표시하지 않는다.

## 검증 경계

자동 테스트와 Chrome 화면 검증은 소프트웨어 흐름을 확인한다. 실제 iPad Safari의 가상 키보드·음성 출력, 모든 영상 자막의 음성 일치, 실제 Supabase의 RLS·동시 저장은 별도 확인이 필요하다. 최종 결과는 [VERIFICATION.md](VERIFICATION.md)에 기록한다.
