# Word Trail — 영어 영상 읽기 학습 PRD

작성일: 2026-09-30 · 버전 1.3 · Chapter 우선 시청과 대화별 학습 흐름 반영

## 1. 제품의 목표

영어를 들으면 조금씩 이해하지만 글자로 읽고 기억하기 어려운 초등학생이, 부모와 함께 익숙한 영상의 소리·뜻·글자를 연결한다. 가장 중요한 성과는 **학습한 단어·표현을 며칠 뒤 글자로 보고 알아보고 읽는 것**이다. 타이핑 정확도, 영상 시청 시간, 읽기 능력을 동일한 지표로 취급하지 않는다.

사용자는 한국어 설명을 활용하는 영어 입문 초등학생과 부모다. 정확한 학년은 미정이며 관찰된 수행 수준으로 도움을 조절한다. 손가락으로 짚으며 읽었을 때 도움이 되었다는 인터뷰 관찰을 단어 추적 UI의 가설로 반영한다. 난독증·주의력 문제의 진단이나 치료 효과를 주장하지 않는다.

작업명은 **Word Trail / 워드 트레일**이다. Bluey 공식 서비스로 오인할 브랜딩, 공식 캐릭터의 복제 UI는 사용하지 않는다.

## 3. 브레인스토밍의 결론

**검토한 안 A — 빈칸 타이핑 중심:** 원래 요청을 직접 구현하지만, 글자 읽기·철자 회상·기억이 모두 어려운 학습자에게 실패 원인을 구분하기 어렵다.

**검토한 안 B — 영상에서 단어를 짚고, 도움을 줄이며 읽기:** 무자막 듣기와 빈칸 타이핑은 유지하되 단어 추적, 소리 도움, 단계별 힌트, 부모의 읽기 확인을 추가한다. 이 안을 채택한다.

**검토한 안 C — 자유로운 AI 회화/영상 업로드 서비스:** 비용·콘텐츠 품질·범위가 커지고 첫 목표와 거리가 있다. 이번 버전에서 제외한다.

서로 다른 능력의 기록을 분리한다: (a) 소리/뜻 도움 사용, (b) 빈칸 철자 입력, (c) 부모가 확인한 독립 읽기, (d) 시간이 지난 후 읽기. 객관식 정답만으로 읽기 습득을 판정하지 않는다.

## 4. 학습 흐름

1. **영상과 Chapter 고르기:** 대본의 명시적 Chapter/챕터 제목과 약 5–15초의 짧은 대화를 사용한다. 일반 자막 cue만으로 공식 Chapter 경계를 추측하지 않는다. 사용자가 지정한 경계는 목표 길이를 맞추기 위해 다시 합치지 않는다. 목차가 없거나 일부만 확인되면 그 상태를 표시하며 공식 YouTube Chapter로 꾸미지 않는다. 원본 cue와 명시된 부모 묶음은 내부 참조로 보존한다. 재생 범위와 받아쓰기 원문은 같은 대화다. 타임스탬프 보정과 음성 미검증 상태를 자료에 기록한다.
2. **Chapter 먼저 보기:** 선택한 Chapter 범위를 대화 사이에서 멈추지 않고 먼저 재생한다. 끝까지 재생되면 첫 대화의 듣기 단계로 이동하고, 이미 시청한 경우에는 명시적 완료 버튼으로 대화 학습을 시작한다. 대화 학습 중에는 Chapter 전체 다시 보기를 제공한다. 듣기 단계에서는 앱의 영어 답안을 숨기고, 대화 반복과 속도 조절을 제공한다. YouTube 자체 CC는 플레이어에서 직접 끈다. 속도 메뉴는 0.5–1.2배 요청값을 제공하되 현재 영상에서 YouTube가 실제 지원한다고 보고한 값만 활성화한다.
3. **받아쓰기와 단어 선택:** 들은 문장 전체를 입력하고 원문과 비교한다. 이번에 빠뜨리거나 다르게 쓴 원문 단어를 자동 선택하고, 추가로 공부할 단어를 원문에서 누를 수 있다. 이번 답안을 모두 맞히면 이전 오답을 자동 선택하지 않는다. 불필요하게 추가한 단어는 오류 설명에만 표시한다.
4. **선택 단어 학습:** 영상은 일시정지하고, 뜻·표현 → 짚어 읽기 → 철자 쓰기 → 빈칸 → 소리 퀴즈 → 뜻 퀴즈 → 혼자 읽기 순서로 안내한다. 정답 저장 후 자동으로 다음 단계와 다음 단어로 진행한다. 자동 진행을 끄거나 단계를 건너뛰고 직접 고를 수 있다. 왼쪽에는 선택 단어 목록과 영상 복귀 버튼을 제공한다. 준비된 여러 단어 표현은 하나의 학습 항목으로 사용할 수 있으나, 화면에서 임의의 연속 단어를 직접 묶는 기능은 제공하지 않는다.
5. **철자와 퀴즈:** 철자 입력 시 글자 이름만 읽고 새 글자와 입력 단어를 확대해 보여준다. 빈칸은 해당 문장 전체의 YouTube 원본 구간을, 소리 퀴즈는 해당 단어/표현의 기기 음성을 반복한다. 원본 영상 구간이 정확히 확인되지 않으면 안내하며 다른 음성으로 대체하지 않는다. 뜻 퀴즈는 한국어 뜻만 제시하며, 소리 퀴즈에서는 정답 단어·IPA·원문·관련 제목을 제출 전 가린다. 혼자 읽기는 IPA와 강세를, 뜻·표현은 준비된 관련어·품사별 예문 묶음을 제공한다. 입력과 채점은 독립적으로 기록한다.
6. **단어장과 복습:** 최초 등록일·출처 영상·연습 횟수·종류별 결과를 표시한다. 과거 단어 이력은 현재 오답과 분리한다. 부모가 확인한 독립 읽기와 시간 간격 복습은 철자 정답과 별개로 저장한다.
7. **학습 자료:** 현재 선택한 단어만 HTML 교재와 카드로 내보낸다. 준비된 한국어 뜻·IPA·설명을 활용하며 기존 표현은행과 일치하는 표현에는 새 대화 두 세트를 연결한다. 미등록 뜻은 부모가 입력할 수 있다.

상세 critic 검토와 원본 묶음 처리 결정은 [WORKSPACE_REDESIGN.md](WORKSPACE_REDESIGN.md)에 정리한다. 새 학습 자료는 콘텐츠 버전으로 구분하며 이전 진도를 다른 구간에 자동 연결하지 않는다.

## 5. 무료 자동 준비

기본 경로는 **대본 + 직접 작성한 표현은행 → 검증 가능한 자동 조립 → 저장된 학습자료 재사용**이다. 실시간 유료 LLM 호출이 필요 없다. 표현은행은 뜻, IPA, 설명, 대화 두 세트를 갖추며 영상에서 실제 일치하는 항목만 선택한다. 일반 규칙으로 만든 결과를 AI가 새로 이해한 장면이라고 표시하지 않는다.

첫 구현은 규칙 기반 자동 조립을 사용한다. 로컬 Ollama를 통한 배치 보강은 후속 옵션이며 현재 구현 범위에 포함하지 않는다. 추후 도입 시 모델 출력의 JSON 스키마와 출처를 검사하고 오류 시 기존 자료로 복귀한다. 사용자 계정·아동 답변을 생성 모델에 전달하지 않는다. 공개 웹앱은 개인 Mac이 꺼져도 준비된 자료로 동작하도록 구성한다. 현재 자료에는 자동 조립 방식과 출처 상태를 기록한다.

사용량 기본안은 계정당 하루 새 학습 시작 10회, 이미 학습한 표현의 복습은 무제한이다. 재사용 콘텐츠에 불필요한 생성 비용을 부과하지 않는다. 공개 모드의 제한은 서버가 시행하고, 설정값으로 변경한다. 무료 플랫폼 한도 초과 시 유료 전환을 자동 실행하지 않는다.

## 6. 데이터와 품질

- 원본 TXT 84개와 정리본 TXT 84개의 짝을 보존한다. 원본에는 8,942개 cue, 정리본에는 9,571개 cue가 발견되었다. 정리본의 114개 0초 cue는 원본 겹침 구간으로 보정하거나 학습 타깃에서 제외하고 이유를 기록한다.
- 원본/정리본의 차이를 출처 메타데이터로 유지한다. 자동 자막을 음성 검증 완료 대본으로 표시하지 않는다.
- 영상 ID·제목·길이·원본 파일·cue·구간·표현·문제·콘텐츠 버전을 연결한다. `0 <= start < end <= duration`을 검증하며 원본 길이가 끝 cue보다 짧은 경우 숨기지 말고 기록한다.
- 표현의 실제 출현 위치와 빈칸 정답을 연결한다. LLM이 만들어낸 원문/타임스탬프를 허용하지 않는다.
- IPA는 넓은 표기의 학습용 미국 영어 발음이며 실제 Bluey 호주 발화와 동일하지 않을 수 있다. 직접 편집한 자료를 특정 사전의 검증 결과로 표시하지 않는다. 기기 TTS 음성/영상 음성을 구분한다. 한글 근사 발음을 영어 철자로 오인하게 만들지 않는다.
- 문법적으로 불완전한 원문과 새로운 완전한 대화 예문을 구분한다. 품질 문제가 있는 자료는 수정/건너뛰기 가능하며, 앱에서 제기한 수정은 원본 증거를 덮어쓰지 않는다.

## 7. 화면과 접근성

화면: 영상 목록, 세 단계 문장 학습실, 등록일·출처·횟수가 있는 단어장과 공통 연습 공간, 복습, 선택 단어 교재·카드 내보내기, 부모 계정/설정.

원색 장식보다 읽기 대상에 집중한다. 밝은 하늘색 바탕, 진한 남색 글자, 선택 단어에 노란 밑줄/배경을 사용한다. 한국어 안내와 영어 학습문장을 분리한다. 가독성 높은 시스템 서체, 읽기 문장 큰 크기, 최소 44px 터치 버튼, 키보드 포커스, 적절한 대비, reduced-motion 지원. 한 화면에서 움직이는 요소를 최소화하고 시간제한 퀴즈를 기본으로 두지 않는다.

Mac 화면에서는 영상과 연습 패널을 나란히, iPad에서는 화면 폭에 따라 세로 배치한다. 외부 모니터 전체 화면에 과도한 행 길이를 만들지 않는다.

## 8. 아키텍처 결정

**선택:** 네이티브 ES module 정적 프런트엔드 + Supabase Auth/Postgres/RLS + Cloudflare 정적 호스팅 배포 구성. 기존 Node/Python으로 준비·검증. 앱 런타임 패키지 의존성 추가 없음.

**근거:** 무료 우선, 공개 가입, 계정별 진도 분리, 고정된 84개 콘텐츠 재사용. 직접 비밀번호 저장/검증 서버를 만들지 않는다.

**대안:** Workers/D1 + 외부 인증은 가능하지만 JWT 검증과 소유권 확인 코드가 늘어난다. 로컬 브라우저 저장만으로는 공개 계정·동기화 요구를 충족하지 못한다. 게스트 학습은 보조 모드이며 계정 기능 완료의 증거로 삼지 않는다.

`public/data`에 준비된 콘텐츠, Supabase에 계정별 최소 진도/학습자 별칭/리뷰 기록. 브라우저에는 공개용 키만 제공한다. 새 콘텐츠 모델 생성은 로컬 관리 작업. 모든 사용자 입력/외부 텍스트는 데이터로 처리하고 HTML 출력 시 이스케이프한다.

## 9. 공개 서비스와 출시 조건

부모 계정 아래 별칭 기반 학습 프로필을 둔다. 실명·생년월일·아동 이메일·음성 녹음을 기본 수집하지 않는다. 계정 간 데이터 접근을 RLS로 거부한다. 로그아웃/계정 전환 시 진도가 섞이지 않으며 삭제/내보내기를 제공한다.

부모 계정 화면만으로 아동 개인정보 규정 준수가 입증되지는 않는다. 실제 공개 전에 데이터 흐름·필요한 동의·YouTube 아동 대상 서비스 정책과 원문 재배포 권한을 확인한다. YouTube 공개 영상이라는 사실은 자막 전체/교재의 재배포 허가와 동일하지 않다. 무료로 개발·검증 가능한 작업은 진행하고, 미확정 출시 조건은 완료로 표시하지 않는다.

외부 출시 준비: Supabase 프로젝트/공개 키/인증 redirect, 실제 확인 메일 SMTP, Cloudflare 계정/배포, 이용·개인정보 문서, 콘텐츠 공개 권한. 현재 계정/자격 증명은 제공되지 않았다. 로컬 기능·통합 코드는 구현하되 실제 이메일 가입, RLS 실행, 교차 기기 동기화, 공개 URL은 실제 환경으로 확인하기 전 검증 완료로 주장하지 않는다.

## 11. 위험과 대응

1. **무료 한도·모델 중단:** 준비된 콘텐츠가 핵심 학습을 유지. 한도와 서비스 중단 상태를 명시. 유료 자동 전환 없음.
2. **자막 오류·잘못된 문제:** 출처-답안 검증, 원본 보존, 자동 자막 표시, 수정/건너뛰기. 오디오 검증을 수행한 것처럼 표현하지 않음.
3. **읽기보다 타이핑 좌절:** 단계별 도움과 부모 관찰 기반 읽기 체크. 오답에서 이동 가능.
4. **계정 간 진도 혼합:** 소유권 RLS·사용자별 저장 키·로그아웃 격리·원자적 제한. 실제 DB에서 교차 계정 테스트 필요.
5. **공개 권리·아동 데이터:** 최소 수집과 릴리스 체크. 권한이 없는 콘텐츠를 외부 공개했다고 주장하거나 실제 배포하지 않음.
6. **YouTube 플레이어 UI:** 초기 불필요한 cue/정지 전환을 줄이되 YouTube의 제목·브랜드·`동영상 더보기`·관련 영상 안내를 앱이 완전히 숨길 수 있다고 약속하지 않음. `rel=0`은 관련 영상을 제거하지 않고 같은 채널 영상으로 제한한다.
