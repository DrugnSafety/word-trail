# v1.2.0 — 손글씨 철자쓰기와 문장 카드

날짜: 2026-10-07 (America/New_York)

철자쓰기에서 **손글씨**를 선택하고 손가락·터치펜으로 따라 쓰기, 보고 쓰기, 듣고 쓰기를 연습합니다. 실제 획만 PNG로 내보내 GPT-5.4가 인식하며 정답·따라쓰기 안내 글자는 전송하지 않습니다. 인식한 글자를 읽고 **다 썼어요**를 누르면 인식한 단어 → 전체 알파벳 철자 → 단어 순서로 재생합니다. 불확실한 인식은 후보 확인·직접 수정을 거치며 지우기·새 획·모드 변경 시 이전 답과 늦은 응답·음성을 취소합니다. 단어의 발음 묶음·IPA와 음절·강세를 표시합니다. 음소는 IPA로 표시하고 영어 단어와 일반 알파벳 이름을 읽습니다.

상단 **문장 카드**에서 영상·Chapter·학습 주제와 저장·복습할 문장을 골라 공부합니다. 원본 듣기 → 뜻 → 표현 묶음 → 빈칸 → 순서 맞추기 → 혼자 말하기 → 복습으로 진행합니다. 영어 뜻풀이를 한국어보다 먼저 표시하고 쓰는 상황·응용 패턴·예문을 한 AI 응답으로 받습니다. 현재 카드와 다음 두 카드의 설명을 최대 두 요청으로 미리 준비합니다. 빈칸·순서·회상 단계에서는 전체 정답을 가립니다.

카드는 영상 원본 대본의 문장과 위치를 그대로 보존합니다. 한 구간에 문장이 여러 개면 재생은 **원본 대화 듣기**로 표시하며, 없는 문장별 타임스탬프를 생성하지 않습니다. 카드 저장과 도움받음·혼자 말함 기록 및 복습 날짜는 단어 진도와 분리됩니다. 닫힌 화면·계정 변경 뒤 늦은 요청과 중복 저장을 차단합니다. 원본 구간이 2,000자보다 길면 잘라 저장하지 않고 카드 대상에서 제외합니다.

## 변경 파일

- `public/lib/handwriting.js`, `public/handwriting.css`: 획 입력·안내선 분리, 인식 후보와 수정, 모바일 쓰기 영역.
- `public/lib/study-speech.js`, `public/lib/study-guide.js`: 전체 철자 재생·취소, 발음 묶음 표시, 설명 선조회·계정 범위 취소.
- `public/lib/sentence-cards.js`, `public/sentence-cards.css`: 원본 문장 추출과 일곱 단계, 필터·복습 저장 상태.
- `public/app.js`, `public/index.html`, `public/styles.css`, `public/lib/store.js`: 학습 화면·탐색·진도 연동, 원본 위치 검증.
- `api/handwriting.js`, `api/study-guide.js`, `server/study-service.mjs`, `server/runtime.mjs`, `server/http.mjs`, `scripts/serve.mjs`: 엄격한 응답 구조·이미지 형식 검증·본문 크기 제한. 기존 API 키 회전·일일 토큰 원장·IP 요청 제한을 공유합니다. 필기 이미지는 영구 캐시하지 않습니다.
- `supabase/migrations/202610070001_sentence_cards.sql`, `supabase/schema.sql`: 구간별 문장 20개와 단어 5개 제한을 분리하고 INSERT·UPDATE에서 원본 위치를 검증합니다. UTF-16 이모지 경계도 검사합니다.
- 관련 단위 테스트와 `scripts/qa-study.mjs`, 기존 QA의 새 API 모의 응답, 설명·버전 문서. 새 npm 의존성은 없습니다.

- 실제 GPT-5.4: `rain` 발음 가이드 401토큰, 합성 필기 이미지의 `rain` 인식 306토큰, 두 요청의 예약 잔여 0. 실제 HTTP에서 `I can't wait to see you.` 영어·한국어 뜻, 상황·패턴·원문 일치 묶음·예문 2개 응답을 확인했습니다. 동일 응답 재조회에서 추가 토큰 사용 0.
- 임시 PostgreSQL 17.11에서 실제 trigger를 실행했습니다. 이모지 앞 문장의 올바른 UTF-16 위치는 저장되고, surrogate 중간 위치·문자열 위치값·원본 불일치는 INSERT·UPDATE에서 거부됩니다. 문장 20/21과 단어 5/6 경계가 각각 적용됩니다. 기존·운영 DB는 변경하지 않았습니다.
- 독립 코드 검토: 남은 차단 이슈 0.

운영 주소: [Word Trail](https://word-trail-three.vercel.app). Vercel 배포 `dpl_5rNxoWN8NQqiu3KPF3VU1R4jNNMm`는 **READY**이며 기존 공개 주소에 alias되었습니다. 공개 앱·스타일·학습 모듈·카탈로그 11개 파일의 HTTP 200과 로컬 SHA-256 일치를 확인했습니다. 공개 주소에서도 새 기능 Chrome 검사 19개·오류 0이 통과했습니다. 인증 없는 실제 공개 API의 단어·문장 설명과 합성 필기 `rain` 인식 응답은 각각 HTTP 200이며 캐시 재조회 사용량이 증가하지 않았습니다.

실제 사용자 Chrome의 공개 사이트에서 원본 Faceytalk 문장 카드와 영어·한국어 뜻·상황을 확인했습니다. 처음 설명 요청은 실패 안내로 표시되었고 재시도 후 정상 설명이 표시되었습니다. 사용자의 기존 단어 학습 기록은 보존했으며 새 카드는 이 확인 과정에서 저장하지 않았습니다.

## 검증 범위

현재 공개 사이트의 Supabase 설정은 비어 있어 게스트 저장을 사용합니다. 계정용 migration은 준비하고 로컬 PostgreSQL에서 검사했으며 운영 Supabase 적용·계정 간 RLS·다중 기기 동기화는 확인하지 않았습니다. 실제 iPad Safari·물리 터치펜 필기 인식률·스피커 청취 품질·학습 효과는 미검증입니다. 합성 필기 실호출은 실제 어린이 손글씨 정확도를 입증하지 않습니다.

원본 위치 구현 근거: [PostgreSQL 문자열 함수](https://www.postgresql.org/docs/current/functions-string.html)에서 UTF8 `ascii`는 Unicode 코드 포인트를 반환하고 substring 위치는 문자 단위입니다. 브라우저의 UTF-16 위치와 일치하도록 검사했습니다. 기능 계약과 참고 앱은 [손글씨·문장 카드 설계](../HANDWRITING_SENTENCE_CARDS.md)에 기록했습니다.
