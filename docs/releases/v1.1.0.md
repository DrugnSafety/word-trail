# v1.1.0 — 철자쓰기 기억 소리

날짜: 2026-10-06 (America/New_York)

철자를 입력할 때 A–Z에 서로 다른 고정 음높이를 가진 짧은 음을 더합니다. 같은 글자는 대소문자와 관계없이 같은 음을 사용하므로 같은 단어를 다시 쓰면 같은 소리 흐름이 나옵니다. 알파벳 이름은 선택한 영어 목소리로 읽으며 A는 기존 /eɪ/ 녹음을 유지합니다.

음성 설정에 **철자쓰기 기억 소리**를 추가했습니다. 효과는 기본으로 켜져 있고 이 브라우저에 켜기·끄기를 저장합니다. **A·B·C 기억 소리 듣기**로 비교할 수 있습니다. 화면·계정 전환, 정지, 설정 닫기에서는 짧은 음과 글자 읽기를 함께 취소합니다. 음 생성 기능을 사용할 수 없으면 기존 글자 읽기를 사용합니다.

## 변경 파일

- `public/lib/letter-tones.js`: 글자별 26개 음높이, 90ms 음과 음량 envelope, 설정 저장, 입력 동작에서 AudioContext 재개, 취소 세대 및 노드 정리.
- `public/lib/learning.js`: 기존 직렬 글자 재생에 기억 소리를 연결하고 취소 시 함께 정지.
- `public/app.js`, `public/styles.css`: 설정, 샘플, 철자쓰기 안내.
- `tests/letter-tones.test.mjs`, `tests/learning.test.mjs`, `scripts/qa-letter-tones.mjs`: 서로 다른 음, 같은 글자의 반복 일관성, 저장된 설정, 취소, 실제 브라우저 음 생성 검증.
- `package.json`, `README.md`, `docs/releases/`: 1.1.0 버전 및 버전별 Markdown 기록 규칙.
- `.github/workflows/pages.yml`: 모든 main 변경에서 빌드·테스트·구문 검사를 실행합니다. Pages 게시 단계는 저장소 변수 `DEPLOY_GITHUB_PAGES=true`일 때 실행합니다. 기존 실행은 Pages 사이트 미설정으로 실패했으며, 현재 운영 사이트는 Vercel입니다.

GitHub에는 이전 Vercel 전용 업데이트도 함께 동기화합니다. 뜻·예문·관련어 통합 AI 응답, 다음 단어 선조회, 받아쓰기·반복 재생 수정, 개인 영상 목록 관련 코드를 포함합니다. 비밀 환경변수·API 키·로컬 사용자 기록·임시 검증 파일은 게시하지 않습니다. 새 npm 의존성은 없습니다.
