# 손글씨와 문장 카드 · v1.2.0 구현 계약

2026-10-07. 사용자가 승인한 두 가지 개편을 기존 학습 기록·계정 범위·원본 대본을 보존하며 구현한다.

## 손글씨

철자쓰기에서 키보드와 손글씨를 선택한다. 손가락·펜으로 캔버스에 쓴 실제 필기를 인식하며 따라쓰기, 보고쓰기, 듣고쓰기 안내를 제공한다. 서버에는 정답이 아닌 필기 이미지와 인식 종류만 보내고 원본 이미지는 저장하지 않는다. 인식 결과가 애매하면 확인 후 반영하고, 확정된 새 글자만 음성으로 읽는다. 전체 철자는 글자를 생략하지 않고 한 번 읽는다. 지우기·되돌리기·화면 및 계정 전환은 오래된 인식·재생을 취소한다.

발음 묶음과 음절·강세는 별개로 표시한다. AI가 반환한 묶음은 원래 철자와 이어져야 하며 발음기호를 TTS에 넣거나 철자 묶음을 그대로 읽어 파닉스 발음으로 가장하지 않는다. 자연스러운 단어 발음과 전체 철자를 들으며 표시를 비교한다.

## 문장 카드

원본 대본의 문장 경계를 보존하고 한 문장을 한 카드로 제공한다. 카드별로 원래 대화·영상·챕터·콘텐츠 버전을 연결한다. 한 대화에 여러 문장이 있으면 재생 버튼을 '원본 대화 듣기'로 표시하고 실제 문장별 시간이 있는 것으로 가장하지 않는다. 영어 설명 다음에 한국어 뜻, 사용 상황, 의미 묶음, 표현 패턴, 응용 예문을 제공한다.

듣기, 뜻 확인, 묶음 읽기, 빈칸, 순서 맞추기, 혼자 말하기와 복습을 연결한다. 사용자가 고른 카드만 저장하며 독립적으로 복습 일정을 가진다. 저장은 기존 계정 범위와 CAS 진도 저장을 사용한다. 현재·다음 카드의 설명은 제한된 동시 요청으로 선조회한다. 기존 단어 학습의 완료 여부와 별도로 집계한다.

## 검증과 완료 조건

인식 데이터 계약·실제 필기와 오답 구분·예산/캐시·취소 경합·원문 경계·진도 저장을 자동 검사한다. 실제 Chrome에서 그리기·인식·철자 순서·카드 저장/복습과 모바일 너비를 확인한다. GPT-5.4 실호출은 적은 수의 생성 예시로 확인하고 실제 손글씨 이미지와 구분한다. 전체 테스트·구문 검사·빌드·기존 학습 회귀를 통과한 뒤 GitHub 버전 기록과 Vercel 공개 파일·API를 읽어 확인한다. 실제 iPad Safari 및 사용자 손글씨 정확도 평가는 별도 미검증으로 명시한다.
