# 짧은 받아쓰기와 원본 문장 음성

2026-09-29 · 콘텐츠 버전 `2026.09.29-2`

## 구간 길이 재수정

사용자 피드백에 따라 15–30초 문단을 폐기하고 약 5–15초의 짧은 대화로 다시 생성했다. 84개 영상에 선택 가능한 구간 3,218개, 중앙값 7초, 최대 15초다. 3,165개는 5–15초이고 명시된 짧은 문장과 경계 조각 53개는 5초 미만이다. 목표 길이를 맞추려고 사용자가 지정한 구문을 다시 합치지 않는다.

Faceytalk의 첫 네 구간은 각각 26–34초, 33–37초, 37–41초, 41–49초다. 첫 구간의 `Uss!`가 기존 캡처에서 33–34초여서 다음 구간과 1초 겹치며, 원본 참조와 미검증 시각 표시를 유지한다. 재생과 받아쓰기에는 동일한 구간 전체를 사용한다. 실제 음성과 초 단위 경계를 전수 대조했다고 주장하지 않는다.

명시 구간은 `content/transcript-groups.json`에 보존한다. 나머지는 원본 cue를 추가로 쪼개지 않고 문장부호·쉼을 참고해 묶는다. 원본 자동 자막 자체가 문장 중간에 끊긴 경우까지 완결된 문장 경계를 보장하지는 않는다.

## Chapter 확인 상태

사용자가 제공한 첫 Chapter 이름 `Facey talk initiates`와 26초 시작, 첫 네 구간만 확인했다. `content/chapter-metadata.json`에 사용자가 제공한 출처와 `confirmed-excerpt`를 기록한다. 49초는 확인된 발췌 구간의 끝이며 Chapter 1의 실제 끝이라고 단정하지 않는다.

YouTube 페이지 조회에서는 전체 Chapter 정보가 반환되지 않았고 로컬 네트워크 조회도 DNS 오류로 실패했다. 나머지 6개 Chapter 제목·시각은 사용자에게 텍스트를 요청한 상태다. 이후 대화는 ‘목차 확인 중’ 아래 계속 연습할 수 있다. 이를 Chapter 2라고 번호 붙이거나 7개 Chapter 구분이 완료됐다고 표시하지 않는다. 화면은 ‘7개 Chapter 중 첫 목차 일부 반영’과 확인 범위를 안내한다.

기존 다른 영상의 대본 목차와 Cubby 제목 보정은 유지한다. 생성된 126개 목차 노드에는 전체 영상·도입부·미확인 나머지 영역도 포함되어 있으므로 모두 공식 YouTube Chapter라는 뜻은 아니다.

## 빈칸 음성

빈칸에서는 선택 단어의 TTS를 제거하고 해당 문장 전체의 YouTube 원본 구간을 반복한다. 학습 길잡이에 실제 영상 플레이어를 표시하며 ‘문장 처음부터 듣기’와 ‘문장 반복 시작/멈추기’를 제공한다. 브라우저가 자동 재생을 막으면 영상 안의 재생 버튼을 안내한다. 소리 퀴즈의 단어 TTS는 유지한다.

영상 ID·콘텐츠 버전·구간 ID·저장된 기준 문장이 모두 현재 자료와 일치할 때만 재생한다. 과거 버전의 단어 기록은 보존하지만, 대응 범위를 확정할 수 없으면 안내하고 다른 문장이나 TTS로 바꿔 재생하지 않는다.

답 제출·다른 단계/단어/화면/계정으로 이동·탭 숨김 시 반복과 준비 중인 자동 재생을 취소한다. 저장 실패나 탭 복귀 후에는 버튼으로 직접 재시작할 수 있다. 재렌더링과 창 종료에서는 이전 문장 플레이어를 해제한다. DB 스키마와 의존성은 변경하지 않았다.

## 검증과 한계

문장 매칭·전체 범위 재생·준비 중 취소·재시작·오래된 비동기 요청 폐기·목차 발췌 표기·원본 참조 보존을 자동 검증한다. `scripts/qa-practice.mjs`에도 실제 문장 플레이어 연결, 단어 TTS 미사용, 제출/탭 이탈 정지 점검을 반영했다.

이번 세션에서 서버는 `listen EPERM`, Chrome은 실행 직후 종료와 `kill EPERM`으로 실패했다. 브라우저 흐름과 실제 음성 출력·YouTube 재생·모바일 화면 검증은 수행하지 못했다. 상세 결과는 [VERIFICATION.md](VERIFICATION.md), 브라우저 실행 실패는 [로그](../tmp/short-dialogue-browser.log)에 남긴다.
