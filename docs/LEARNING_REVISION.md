# 대화 구간·입력·재생 개정

2026-09-29 · 콘텐츠 버전 `2026.09.29-1`

아래는 이전 개정 기록이다. 이후 사용자 피드백으로 구간을 5–15초로 다시 줄이고 빈칸 음성을 YouTube 원본 문장으로 변경했다. 현재 계약과 Chapter 확인 상태는 [SHORT_DIALOGUE_AUDIO.md](SHORT_DIALOGUE_AUDIO.md)에 있다.

## 목차와 대화 구간

기존 1–10초 자막 구간 8,901개를 원문 순서·문장부호·쉼·대본 목차를 참고해 1,412개 대화 구간으로 묶었다. 중앙값 17초, 최대 30초이며 1,265개가 15–30초다. 나머지 147개는 Chapter 끝, 긴 쉼, 비음성 구간 앞뒤 등의 짧은 조각이다. 원문을 다른 영어 문장으로 바꾸지 않았다. 요청의 paraphrase는 ‘대화·문단 단위’로 해석했다.

6개 영상의 Markdown 대본에 있던 에피소드 제목 41개를 Chapter 목차로 사용한다. 제목 앞 대사는 별도 도입부로 두며, 제목이 없는 78개 영상은 전체 영상 아래 대화 목록을 제공한다. 전체 목차 노드는 도입부·전체 영상 항목을 포함해 125개다. YouTube에서 새로 가져온 공식 Chapter라고 표시하지 않는다.

`Cubby`의 대본 소제목 `Puppy`는 영상 제목과 충돌하는 캡처 오류여서 화면 목차를 `Cubby`로 보정했다. `capturedTitle: Puppy`와 보정 근거를 남기고 원문 대사는 변경하지 않는다. 화면에서도 제목 보정 사실을 알린다.

5개 대본 목차 시각이 원본 자막 중간에 걸친다. 단어를 잘라내지 않도록 해당 자막 시작으로 1–4초 앞당기고, 원래 `markerStart`와 `snapSeconds`, 사유를 보존한다. 목차와 대화 구간의 순서, 재생 범위, 원문 참조를 검증한다. 음성과 실제 의미 경계를 사람이 전수 대조한 결과는 아니다.

재생 범위와 받아쓰기 정답은 같은 대화 전체를 사용한다. 기존 단어·읽기 이력은 유지하고, 새 구간 번호에 과거 답안을 잘못 연결하지 않도록 콘텐츠 버전을 바꿨다. 과거 버전의 단어는 단어장에서 계속 연습할 수 있다.

## 선택·입력 화면

- 받아쓰기 저장 후 ‘연습할 단어를 눌러 고르세요’로 스크롤하고 제목에 포커스를 둔다. 선택을 누를 때 내부 스크롤 위치를 유지한다.
- ‘연속된 단어를 직접 묶기’ 화면은 삭제했다. 준비된 표현 선택과 이전에 저장한 표현의 이력은 유지한다.
- 철자 음성은 대문자 문자 대신 `ay`, `bee`, `cee` 등 알파벳 이름으로 전달한다. 입력한 대소문자를 화면에 그대로 표시하고 모바일 자동 대문자 변환을 끈다.
- 입력 단어를 크게 표시하고, 최근 글자에 다른 색과 밑줄을 적용한다. 원래 연습 단어도 크게 강조한다. 모션 줄이기 설정은 유지한다.
- 입력칸과 확인 버튼은 같은 줄이다. 답안 폼과 설명 영역을 분리해 설명만 내부 스크롤한다. 바깥 연습 카드는 내용에 맞게 늘어나며 작은 화면에서는 페이지를 스크롤할 수 있다.

## 영상 재생

구간을 고를 때 플레이어를 미리 준비하고, 준비가 끝난 뒤의 클릭은 사용자 동작 안에서 바로 재생한다. `cueVideoById` 후 즉시 `playVideo`를 보내던 경합을 줄이고 명시적 `loadVideoById`로 구간을 시작한다. 구간 전환·일시정지·화면 이탈 시 대기 중인 재생을 취소한다. ‘구간 처음부터’는 재개가 아니라 구간 시작점으로 돌아간다.

속도는 0.25, 0.5, 0.75, 1, 1.25, 1.5, 1.75, 2배속을 제공한다. 영상이 실제로 지원하는 값만 활성화하며, 준비 중 선택한 속도는 지원 목록이 확정될 때까지 보존한다. [YouTube IFrame API](https://developers.google.com/youtube/iframe_api_reference)에 따라 브라우저가 스크립트 재생을 차단하면 영상 안의 재생 버튼을 안내한다. 모든 기기에서 소리 있는 자동 재생을 보장하는 기능은 아니다.

## 완료 단어

단어 공부에 전체 / 공부 중 / 공부 완료 목록을 추가했다. 저장된 독립 읽기 성공이 한 번 이상 있는 단어를 완료로 분류한다. 철자 정답·도움 받은 읽기·단계 건너뛰기는 완료가 아니다. 새로고침 뒤에도 저장 기록으로 복원하며, 완료한 단어도 다시 연습·복습할 수 있다. 새 DB 필드는 필요하지 않다.

## 휴대폰·아이패드 사용

전체 앱은 HTML/CSS/JavaScript 웹앱이므로 별도 네이티브 앱 개발 없이 웹 주소로 사용할 수 있다. 현재 모듈과 JSON을 여러 파일에서 읽으므로 `index.html` 한 파일만 보내서 실행하는 구조는 아니다. 로컬 `file://`에서는 모듈 보안 제약도 있다. [MDN 모듈 안내](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Modules)

권장 제공 방식은 `public/` 폴더를 HTTPS 정적 호스팅에 올리고 모바일 브라우저에서 접속하는 것이다. iPhone Safari에서는 홈 화면에 추가해 웹앱으로 열 수 있다. [Apple 안내](https://support.apple.com/en-my/guide/iphone/iph42ab2f3a7/ios)

현재 `localhost:4173`은 Mac 안의 주소이므로 휴대폰에서 같은 주소로 Mac 앱에 접속할 수 없다. 이번 수정은 공개 배포를 수행하지 않았다. 영상은 인터넷 연결이 필요하고, 게스트 진도는 사용한 브라우저에 저장된다. 내보낸 HTML 교재는 앱 전체와 별개의 자료다.

## 검증 범위

자동 회귀 검증은 `npm test`, 자료 생성은 `npm run build`, 구문 검증은 `npm run check`를 사용한다. 브라우저 QA 스크립트 `scripts/qa-practice.mjs`는 긴 대화·목차, 선택 스크롤, 소문자 표시, 완료 목록 복원, 입력/확인 버튼 정렬 검사로 갱신했다.

최종 전체 테스트 117개와 JavaScript 27개 파일 구문 검사가 통과했다. 전체 빌드 결과는 영상 84개·목차 125개·선택 가능한 대화 1,412개다. 실행 결과와 이전 버전 기록의 구분은 [VERIFICATION.md](VERIFICATION.md)에 있다.

이번 세션은 로컬 서버 포트 열기와 Chrome 실행이 제한되어 브라우저 QA를 실행하지 못했다. Chrome 시작이 종료되고 `kill EPERM`이 보고되었다. 이전 버전의 스크린샷·17개 브라우저 점검 통과 기록을 이번 버전의 검증으로 재사용하지 않는다. 실제 음성 출력, YouTube 재생, 모바일 키보드와 화면 배치는 실제 브라우저에서 확인이 남아 있다.
